Automatic Google Drive backup

Reinstall safely: reconnect the same Google account and the app restores every monthly vocabulary archive.

Dedicated backup folder

The app creates KeepVocab Dictionary Backup in My Drive. It stores one JSON file per adding month, such as Dictionary July 2026.json, plus one settings file. Unrelated Drive files are never read.

Google Drive connection

Access is limited to files this app creates. On this device, the short-lived Drive session is saved locally so reloads stay connected. Disconnecting removes it.
